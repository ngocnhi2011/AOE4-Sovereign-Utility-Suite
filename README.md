## ✨ Key Features: Your Arsenal of Control

The **Legacy Command Suite** is more than a simple adjustment tool. It is a modular ecosystem, each component designed to serve a specific tactical function.

- **Resource Pulse Monitor** 📊
    A real-time, low-overlay dashboard that tracks your gold, food, wood, and stone. Unlike standard UI elements, this monitor is fully customizable in opacity and location, allowing you to keep your eye on the battlefield while still having a pulse on your economy. It is the **spectator seat for your own wallet**.

- **Strategic Time Dial** ⏳
    A sensitive control that allows you to slow down or accelerate the passage of in-game time. This is not about skipping cutscenes; it is about giving you the headspace to analyze a complex battle formation, execute a delicate multi-pronged attack, or simply appreciate the architectural beauty of your Wonder being built. It is a **time-manipulation lens** for the patient tactician.

- **Vision Scope (Single-Player Focus)** 🔭
    A targeted utility that temporarily lifts the fog of war for exploration purposes in custom and single-player skirmishes. This allows you to study the map layout, discover optimal chokepoints, and plan your expansion routes with the precision of a cartographer. It is designed for **reconnaissance and planning**, not for competitive play.

- **Unit Inspector Pro** 🔍
    A deep-dive analysis tool that provides granular details on unit statistics, armor types, and counter bonuses. While the game provides basic info, the Inspector Pro offers a spreadsheet-style breakdown, helping you understand the intricate math behind the rock-paper-scissors combat system. This transforms you from a player into a **statistical analyst**.

- **UI Density Controller** 🎛️
    A quality-of-life feature that allows you to adjust the size and spacing of the in-game interface elements. Whether you are playing on a high-resolution monitor or a compact laptop screen, the Density Controller ensures your command interface is always comfortable and unobtrusive. It is the **tailor for your HUD**.

## 🧭 Installation & Setup: Your Marching Orders

The deployment of the Legacy Command Suite is designed to be as frictionless as possible. We believe that your time is better spent building empires, not wrestling with configuration files. The setup process is a simple three-step procedure:

1.  **Acquire the Package** 📦
    The first step is to secure the latest build of the suite. Ensure you have downloaded the archive from the authorized distribution point. The package is compressed for efficient transfer, so you will need a standard unarchiving utility (like WinRAR or 7-Zip) to extract its contents.

2.  **Select Your Installation Path** 📁
    Once extracted, you will find a folder named `Legacy_Command_Suite`. This folder is entirely portable. You can place it on your primary system drive or even on an external storage device. The suite does not write to any system directories, making it one of the most **non-invasive strategic tools** available. To activate it, simply run the `LegacyCommand.exe` executable.

3.  **Initiate the Connection** 🔌
    The suite operates by interacting with the game's memory process in real-time. Therefore, it is imperative to launch the *Age of Empires 4* game client *before* starting the Legacy Command Suite. Once the game is running and you are at the main menu, launch the suite. The interface will automatically detect the game process and establish a secure handshake, allowing you to access the controls immediately.

This suite has been engineered with a focus on stability and broad compatibility. It is optimized specifically for the Windows environment.

## 🎛️ User Interface & Experience: Designed for Commanders

We believe that a tool should feel as good as it works. The **Legacy Command Suite** features a modern, minimalist UI that respects the aesthetic of the game itself.

- **Responsive Overlay** 📱
    The interface adjusts dynamically based on your screen resolution. Whether you are running a 1080p setup or a 4K ultra-wide monitor, the overlay scaling ensures that every button and slider is crisp, readable, and easy to access. It is a **chameleon interface** that adapts to its environment.

- **Dynamic Control Panel** 🎚️
    Access all the core features from a single, flattened control panel. This panel can be collapsed into a small, unobtrusive tab that sits on the edge of your screen, allowing you to summon it with a single hotkey. This minimizes UI clutter and maximizes your field of view.

- **Multi-Language Localization** 🌍
    The suite supports a wealth of international languages to serve a global commander base. Available interfaces include English, Spanish, German, French, Portuguese, Russian, Chinese (Simplified), and Japanese. This multilingual support ensures that the tool is accessible to a wide audience.

- **Persistent Profile System** 💾
    Your adjustments are not lost when you exit the game. The suite creates a unique profile for your settings, saving your preferred configurations for the Vision Scope and the Time Dial. This means you can pick up right where you left off, with your tactical preferences perfectly preserved.

## ⚙️ Advanced Usage: Unleashing the Potential

The surface-level features are only the beginning. For the power user, the **Legacy Command Suite** offers a deeper layer of customization.

- **Hotkey Mapping** ⌨️
    Every function within the suite can be remapped to a desired key or key combination. This allows you to integrate the suite's controls directly into your existing muscle memory. It is the ultimate **ergonomic enhancement for your playstyle**.

- **Sensitivity Curves** 📈
    The Strategic Time Dial is not just an on/off switch. You can customize the sensitivity curve, dictating how quickly the time manipulation accelerates. A linear curve offers a predictable progression, while a logarithmic curve allows for fine-grained adjustments at the low end and massive shifts at the high end.

- **The Config Vault** 🗃️
    For those who prefer to work with text files, the suite includes a `Settings.ini` file that serves as a "Config Vault." This file contains every single possible setting, documented with clear comments. Advanced users can edit this file to tweak parameters that are not exposed in the standard UI, offering a **developer-grade level of control**.
